# Contributing to ProyectoIA

Thank you for your interest in contributing.

## Development Setup

```bash
git clone https://github.com/edwin199-sudo/ProyectoIA.git

cd ProyectoIA

docker compose up -d --build
```

## Coding Standards

- Python 3.12
- FastAPI
- PEP8
- Black
- Ruff

## Pull Requests

- Create a feature branch.
- Write descriptive commits.
- Ensure all tests pass.
- Update documentation if needed.
